Explore the block reference

These are the blocks implemented in this repository. The examples below are rendered by the same code used on your pages. Library availability in Experience Workspace is configured separately.

Cards

Use a table headed Cards. Each following row is one card. Put a heading, description, and link together in a cell. An optional image can be in a separate cell. Use consistent cells across rows and meaningful alt text for images.

Columns

Use a table headed Columns. Put related content into the cells of a row: two cells for two columns, for example. Columns stack on narrow screens. Keep reading order sensible without relying on side-by-side presentation.

Hero

Use a table headed Hero for an introductory area containing a heading and supporting text. The existing stylesheet supports a background picture; provide enough contrast and do not put essential information only in the image. Keep one Heading 1 per page.

Fragment

Use a table headed Fragment containing a link to an existing shared page. The shared content must be previewed and published separately. This site also automatically expands links whose paths contain /fragments/; use those links deliberately, because they do more than navigate.

Do not copy a fragment's content into every page to make an update. Change the shared source, then verify the affected pages. No sample fragment is assumed to exist in this starter content.

Widget

The repository includes a Widget block and automatically recognizes links containing /widgets/. Widget targets require their own implementation. Use only a widget path approved by your developer; this guide does not assume any widget endpoint has been configured.

Guide Topics

Use a table headed Guide Topics. Each row contains two cells: a category and the topic content. The content cell has a Heading 3 with a link and a short description. The overview turns these rows into a searchable directory.

Guide Topics
Getting started | Heading 3 link: Create your first page
                | Description: Make a draft and preview it.

Search matches the authored category, title, and description, not the full lesson body. Rows without a link remain readable but are not given a fabricated destination. Missing category names are grouped under Topics.

Shared header and footer

Header and Footer blocks are loaded by the page framework, not normally inserted into a document. Guide pages select their shared source documents using the Nav and Footer metadata rows. See Sections and metadata.

Any variant not documented here should be treated as unsupported until a developer confirms it.
