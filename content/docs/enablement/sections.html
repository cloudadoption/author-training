Organize sections and metadata

Sections group related content. Section metadata controls a group, while page metadata describes the whole page. They are different tables with different jobs.

Group content into sections

Use the editor's section controls to split a page at a meaningful change in topic or layout. In the earlier document editor, a horizontal rule separates sections. Within a section, combine headings, paragraphs, and blocks as needed.

Use the outline to inspect your page structure. Adding a section does not replace the need for a meaningful heading.

Set section metadata

Add a table headed Section Metadata in the section you want to affect. Below the header, use two cells per row: a property name and its value.

Section Metadata
Style | light

This repository supports light and highlight section styles. They apply a light background and section padding. Arbitrary names, spacing values, or colors do not create new styles. The guide template has its own reading layout; check the rendered result before using section treatments in lessons.

Set page metadata

Use one table headed Metadata, normally at the end of the document. Use two cells per row for the key and value.

Metadata
Title       | A clear page title
Description | A concise summary of this page

The guide pages also use Template | guide, Nav | /docs/nav, and Footer | /docs/footer. These select this guide's layout and shared navigation rather than changing the whole site's defaults. Keep these rows when copying a lesson.

Understand shared content

Navigation and footer content are separate documents. Changing a shared document can affect many pages. Preview and review those documents as well as the page you are editing, then publish dependencies before pages that need them.

The guide's left-hand navigation is maintained separately at /docs/guide-nav. A new lesson must also be linked from the overview's topic directory; it is not discovered automatically.

Try it

Give your practice page a useful title and description. Preview it and check the browser tab title. Confirm that page metadata is not showing as a visible table.

Reference: Markup, sections, and blocks. Supported styles come from this repository's CSS.
