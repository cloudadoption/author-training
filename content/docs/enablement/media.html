Add images and media

Choose an image that helps explain the content, add an appropriate text alternative, and check how it behaves on smaller screens.

Upload an image

  1. Use an approved image that you have permission to publish.
  2. Position the cursor in the paragraph or block cell where the image belongs.
  3. Select Add image in the contextual toolbar, choose a file, and open it.
  4. Set the image's alternative text using the available image controls.
  5. Preview the page. Confirm the image loads and is not cropped in a way that removes important content.

Experience Workspace stores document uploads in a hidden folder next to the document. Avoid renaming or moving that folder manually. Use a sensible image size; do not upload a large original when a smaller, optimized asset is sufficient.

Write useful alternative text

Describe the information the image contributes, not every visual detail. For a screenshot, explain the action or state it illustrates. Keep important instructions in the page text too, so the task does not depend on seeing an image.

If an image is purely decorative, use empty alternative text when the editor supports it. For a linked image, the accessible name must make the link's purpose clear. Do not use a file name as alt text.

Use AEM Assets when enabled

If an administrator has configured the integration, the AEM Assets picker lets you select approved shared assets. Those assets must be published and accessible to the delivery service. Dynamic Media assets may have additional approval requirements.

Do not assume the picker is available on every site. A missing integration is a configuration question, not a reason to copy a private asset URL into your page.

Handle video and downloadable files

Experience Workspace accepts several media formats, but upload support does not mean this repository has a custom player or every embed behavior. Agree on the presentation with the site owner. Provide captions or a transcript for meaningful video/audio content and descriptive link text for downloads, including format where useful.

Try it

Add an approved image to your practice page. Verify its alt text, mobile presentation, and loading at the preview URL. If you replace an asset, re-preview the pages that use it.
