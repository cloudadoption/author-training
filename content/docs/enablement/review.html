Review and restore content

Use comments for feedback and versions to understand or recover changes. Neither replaces your organization's approval process.

Ask for focused feedback

  1. Preview the latest draft and share its preview URL with your reviewer.
  2. Explain what changed and what decision or feedback you need.
  3. In the editor, select the relevant content and open Comments from the tools panel or editor menu.
  4. Create a comment thread using the available comment control. On macOS, the documented shortcut is Command + Option + M.
  5. After addressing a thread, resolve it. Re-preview the updated content before asking for a final check.

Comments are tied to the selected content. A resolved comment indicates the discussion is resolved; it does not necessarily mean the page is approved to publish.

Inspect the version history

Open the tools panel and select Versions. The timeline shows edits and saved versions. Preview and publish actions automatically create versions. You can also create a named version with the plus control in the Versions panel before a substantial change.

Select a version to inspect it. Use Compare to see it alongside the current document. Check the labels so you know which side is current.

Restore carefully

  1. Coordinate with anyone currently editing the page.
  2. Create a named version of the current content if you may need it again.
  3. Select the earlier version in the timeline and choose Restore.
  4. Confirm only after checking that it is the intended version. Restoring replaces the current document content.
  5. Preview the restored document, verify it, and follow the normal approval process before publishing.

A restoration is not automatically a live rollback. The live page stays as it is until an authorized publish action updates it. Do not rely on undo after closing or reloading the editing session.

Try it

On your practice page, create a named version, edit one sentence, and compare the two. Restore only if the exercise is isolated and no one else is editing.
