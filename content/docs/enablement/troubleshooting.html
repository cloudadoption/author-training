Solve common problems

Start by checking the page path, environment, and latest preview. Many apparent editing problems are a mismatch between the draft and the URL being viewed.

My changes are not showing

  1. Confirm your edits finished saving.
  2. Check whether you are viewing the draft, preview, or live URL.
  3. Preview again, open the exact URL returned by the action, and reload it.
  4. If preview is correct but live is old, the change has not necessarily been published. Follow the approval process rather than publishing just to test.

If the change is in navigation, a footer, or a fragment, update that shared document too. A code change requires a code deployment; previewing content does not deploy code.

A block looks like a table or plain text

Use Content view to check the block name and table structure against the block reference. Remove accidental spaces or unsupported variants in the name. If the structure is correct, ask a developer to verify that the block code is deployed to the branch you are previewing.

An image is missing

Confirm the source image is still available and you have permission to use it. If it comes from AEM Assets, it must be accessible to the delivery service and meet the integration's publication requirements. Re-preview after replacing media. Do not substitute a private session URL for the source asset.

I cannot preview or publish

Check that you are signed in with the intended Adobe account and are in the correct organization and site. Ask the administrator to confirm the required permission. Include the action you attempted and any message shown, but never share credentials or access tokens.

A link returns a missing page

Check the full path, spelling, and environment. The destination must be previewed for preview links and published for live links. A new page in DA is not automatically reachable on either delivery host. Coordinate redirects when a live page is renamed or moved.

Ask for useful help

Send the site owner the page URL, whether it is preview or live, the block or feature involved, what you expected, what happened, and the steps to reproduce it. Include a screenshot without private information. Mention whether the issue occurs at mobile width or in another browser.
