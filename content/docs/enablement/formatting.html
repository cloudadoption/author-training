Format text and links

Use formatting to describe the meaning of your content. On this site, formatting also determines when a standalone link becomes a button.

Give the page a clear outline

Use one Heading 1 for the page title. Use Heading 2 for main sections and Heading 3 for subsections. Do not choose a heading simply because you want larger text, and do not use bold paragraphs as a substitute for headings.

Use numbered lists for steps that must happen in order and bullet lists for related items. Keep bold for important words and italic for light emphasis. Underline does not trigger a special component on this site.

Write links people can understand

  1. Select meaningful text that describes the destination.
  2. Use the editor's link control to add the URL.
  3. For another page on this site, use a root-relative path such as /docs/enablement/blocks.
  4. Preview and follow the link. Check that it points to the intended page and not an editor URL.

A link inside a sentence remains a text link, even when you emphasize part of the sentence.

Turn a standalone link into a button

The link must be the only text in its paragraph. Apply formatting to the whole link:

  • Bold creates a primary button.
  • Italic creates an outlined secondary button.
  • Bold and italic together create an accent button.

These are site-specific rules, not universal Experience Workspace behavior. A bare URL or a linked image is not turned into a button. Put separate buttons in separate paragraphs.
