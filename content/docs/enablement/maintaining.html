Maintain this guide

Keep training content close to the product authors actually use. A small, accurate guide is more valuable than a large collection of outdated instructions.

Know where things live

  • /index is the overview and searchable topic directory.
  • /docs/enablement holds lessons and the block reference.
  • /docs/guide-nav controls the left-hand topic navigation and lesson order.
  • /docs/nav and /docs/footer are the guide's header and footer documents.

These are recommended destinations supplied with this implementation. Content only appears on delivery hosts after it has been imported and previewed or published.

Add or update a lesson

  1. Copy an existing lesson and retain its Metadata table, including the guide template, navigation, and footer rows.
  2. Give it a unique path, title, description, and one Heading 1.
  3. Start with the task and prerequisites. Write short steps, a way to verify the result, and a link to the relevant official documentation.
  4. Clearly label site-specific conventions. State when a feature depends on configuration or permissions.
  5. Add the lesson to /docs/guide-nav and add or update its row in the overview's Guide Topics block.
  6. Preview the lesson and both updated indexes. Check every new link and the narrow-screen layout before publishing.

Keep the topic directory useful

Each Guide Topics row has a category cell and a content cell containing a Heading 3 link plus a short description. Search checks those authored category names, titles, and descriptions; it does not search the full text of every lesson.

Keep link text descriptive and descriptions distinct. Reuse an existing category when possible. No manually maintained search index or spreadsheet is required.

Update the block reference with code changes

When a developer adds or changes a block, update its content model, supported variants, example, and limitations in the block reference. Confirm the code is available on the target branch before asking authors to use it. Configuring the Experience Workspace library is a separate administrator task.

Review for accuracy

Recheck a lesson when the workspace UI, site behavior, permissions, or publishing process changes. Have an author complete its exercise, verify the official source links, and remove claims that no longer match the project. Initial copy was prepared with AI assistance and should be validated by your site owner before rollout.
