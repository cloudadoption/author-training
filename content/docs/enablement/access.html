Find your workspace

Start in the right site, find the page you need, and choose the editor view that helps you work.

Before you begin

You need an Adobe account with access to this site. Editing and publishing permissions can differ. If an action is missing, ask your site administrator to confirm your role rather than using someone else's account.

Open the content browser

  1. Open your author-training workspace and sign in when prompted.
  2. Check that the organization is cloudadoption and the site is author-training.
  3. Use the folder list and breadcrumbs to move through the content tree. Open a page by selecting its name.
  4. Search to narrow the current folder. Press Enter to search that folder and its subfolders.

Page names and folder paths become part of the published URL. Do not rename or move an existing live page without coordinating links and redirects with the site owner.

Choose an editor view

  • Layout shows the page visually. Select editable content to work in place.
  • Content shows the underlying document, including the tables that define blocks.
  • Split view shows both so you can connect the content model to its rendered appearance.

The editor toolbar is contextual: selecting text, an image, or a table reveals different options. The tools panel provides views such as the content outline, blocks, comments, and versions.

Check which experience you have

Some DA sites still use the earlier document editor. If Layout, Content, or Split view is unavailable, use the document editor guide and ask the administrator about the site's setup. Assistant and asset integration options are not guaranteed to be enabled.

Try it

Find a training page, open it, and switch between the available views without changing content. You are ready when you can identify the page path and locate the tools panel.
