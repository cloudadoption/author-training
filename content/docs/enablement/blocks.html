Build with blocks

A block gives a piece of content a recognizable structure, such as a set of cards or a two-column layout. Start with a supported block rather than inventing a new table name.

Choose a block

Check the block reference for the blocks implemented in this repository. A block can exist in code without being listed in your workspace's library; an administrator configures the library separately.

Use regular paragraphs, headings, lists, and links when they already express the content well. Not every section needs a block.

Insert and edit

  1. Place your cursor where the block belongs.
  2. In Content mode, press / and choose an available block. Alternatively, use the Blocks view in the tools panel or the outline's add-block control.
  3. Replace the sample content without changing the block name or accidentally merging its cells.
  4. Switch to Layout or Split view to inspect the result.
  5. Preview the page and check the block at mobile width.

If your library is not configured, ask the site owner for an approved example to copy. You can also create the documented block table in Content mode when your editor supports table insertion.

Understand the table

The first row names the block. Following rows hold content. In a Cards block, each row becomes a card. In Columns, the cells in a row become columns. The exact model is part of each block's contract.

Options written in parentheses after a block name become variants, but a variant has an effect only when code supports it. Do not assume options from another site's library work here.

Know when to ask a developer

  • You need behavior the existing blocks do not provide.
  • A new variant appears in the document but does not change the preview.
  • Content is correct but the layout fails at a particular screen width.

Share the preview URL, block name, expected result, and a screenshot. Code must be deployed separately; previewing a document does not deploy JavaScript or CSS.

Try it

Use a Cards example to create two cards. Change their headings and links, then verify both cards on the preview page.
